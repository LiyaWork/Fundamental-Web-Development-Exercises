# 💻 Fundamental Web Development Exercises

Welcome to the fundamental web development exercises repository!

This repository documents my learning process and practical implementation of core front-end concepts acquired from an introductory web development course.

---

## 🚀 Repository Goal

The main objectives of this repository are to:
1.  Master the basics of **HTML5**, **CSS3**, and **Vanilla JavaScript**.
2.  Practice essential layout techniques (Flexbox and Grid).
3.  Understand DOM manipulation and event handling in JavaScript.
4.  Provide a structured and organized portfolio of learning progress.

## 📂 Project Structure

The exercises are organized into folders by topic for easy review and navigation.

| Folder | Description | Key Concepts Covered |
| :--- | :--- | :--- |
| **`01_HTML_Basics`** | Exercises on boilerplate elements, common tags, forms, and HTML5 document structure. | Semantic HTML, Page Structure, Forms. |
| **`02_CSS_Styling`** | Practice on selectors, color properties, typography, and the CSS box model. | CSS Selectors, Box Model, Basic Properties. |
| **`03_CSS_Layouts`** | Implementation of common web layouts using Flexbox and CSS Grid. | Flexbox, CSS Grid, Basic Responsive Design. |
| **`04_JS_Intro_Core`** | Exercises on variables, data types, loops, conditionals, and functions in JavaScript. | JS Fundamentals, Control Flow. |
| **`05_JS_DOM_Project`** | Small projects involving manipulating page elements (DOM). | DOM Manipulation, Event Handling. |
| **`99_Mini_Project`** | A small final project integrating HTML, CSS, and JS. | Front-end Integration. |

## 🛠️ How to Run

The exercises in this repository are static files. To run them locally:

1.  Clone this repository to your computer:
    ```bash
    git clone https://github.com/LiyaWork/Fundamental-Web-Development-Exercises.git
    ```
2.  Open the desired **`.html`** file from any of the folders directly in your web browser.
